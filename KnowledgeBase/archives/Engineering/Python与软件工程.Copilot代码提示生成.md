#### python的工程项目实现有哪些常用的设计模式？请举例说明。

1. **单例模式**：确保一个类只有一个实例，并提供全局访问点。
示例：
```python
class Singleton:
    _instance = None

    def __new__(cls, *args, **kwargs):
        if not cls._instance:
            cls._instance = super(Singleton, cls).__new__(cls)
        return cls._instance
```
2. **工厂模式**：定义一个创建对象的接口，但由子类决定实例化哪个类。
示例：
```python
class AnimalFactory:
    @staticmethod
    def create_animal(type):
        if type == "dog":
            return Dog()
        elif type == "cat":
            return Cat()
        raise ValueError("Unknown animal type")

class Dog:
    def speak(self):
        return "Woof!"

class Cat:
    def speak(self):
        return "Meow!"
```
3. **观察者模式**：定义对象间的一对多依赖，当一个对象状态改变时，所有依赖它的对象都会收到通知并自动更新。
示例：
```python
class Subject:
    def __init__(self):
        self._observers = []

    def attach(self, observer):
        self._observers.append(observer)

    def notify(self, message):
        for observer in self._observers:
            observer.update(message)

class Observer:
    def update(self, message):
        print(f"Observer received message: {message}")
```
4. **策略模式**：定义一系列算法，将每个算法封装起来，并使它们可以互换。策略模式让算法独立于使用它的客户。
示例：
```python
class Context:
    def __init__(self, strategy):
        self._strategy = strategy

    def set_strategy(self, strategy):
        self._strategy = strategy

    def execute_strategy(self, data):
        return self._strategy.execute(data)

class StrategyA:
    def execute(self, data):
        return [x * 2 for x in data]

class StrategyB:
    def execute(self, data):
        return [x + 1 for x in data]
```
5. **装饰器模式**：动态地给一个对象添加一些额外的职责。就增加功能来说，装饰器模式比生成子类更为灵活。
```python
def decorator_function(original_function):
    def wrapper_function(*args, **kwargs):
        print("Wrapper executed before {}".format(original_function.__name__))
        return original_function(*args, **kwargs)
    return wrapper_function

@decorator_function
def display():
    print("Display function executed.")
```
